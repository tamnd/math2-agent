# The align role

## 0.1.0

The first version. The model reads the records of the other systems and proposes the crosswalk edges same_as, close_to and aligned from the target node with the tool propose_edge. A person accepts or rejects each proposal. The model can also append a Mathlib binding to the target when the type hash of the Mathlib declaration is the type hash of a Math2 binding of the node. The run succeeds when m2 check finds nothing in the changed nodes, and the judge in checks/judge.md finds the verdict same for each same_as proposal and a verdict that is not different for each close_to and aligned proposal.
