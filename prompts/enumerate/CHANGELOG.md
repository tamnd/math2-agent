# The enumerate role

## 0.1.0

The first version. The model lists the items of one cell, an MSC code at five digits and a level, that are not in the inventory yet. Each item becomes a mention of the source model-FAMILY with its kind, its name and aliases, a statement of one sentence, the names of its prerequisites and the sources that the model names. The run succeeds when it adds at least one mention and the changes are inside the field permission set of enumerate.
