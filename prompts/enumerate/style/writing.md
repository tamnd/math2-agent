# Writing conventions of an item list

- Write the statement of each item in one sentence, in your own words. Do not copy the sentence of a book or a page.
- Use the common name of the item, as a textbook or Wikipedia gives it, for example "Heine-Borel theorem". Put the other names in the aliases.
- Write the prerequisites by their common names, for example "compact space" and "closed set".
- Use LaTeX in $...$ for formulas.
- Give an ISBN with the theorem or the page in the locator, for example 978-0-07-054235-8 with the locator Theorem 2.41.
- Give a Wikipedia source with the exact page title, for example Heine–Borel theorem.
- Do not use em dashes.
