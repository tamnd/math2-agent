# The write role

## 0.1.0

The first version. The model takes one node to the next writing level. It writes the sections that the card of the kind asks for at that level, other than the explanations and History, and it can add example nodes and informal proof nodes of the target. The run succeeds when the changes are inside the field permission set of write, m2 check finds no problem in the changed nodes, the card of the level has each section, example and proof that write makes, each proof is a list of numbered steps, each definition names its term in bold, and the run changed no section that a person wrote or confirmed. For a W3 job the house style must also find no new problem. When the run has a reference corpus, the copy check must find no copy of a source whose licence math2 cannot take.
