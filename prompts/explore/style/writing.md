# Writing conventions of math2

- Write plain English with short sentences.
- Use LaTeX in $...$ for formulas, as the node files do.
- Write a link as [[text|TAG]], where TAG is the tag or the provisional id of a node, for example [[a group|G5S1M9]]. Do not link to a URL.
- In a conjecture, give the bound to which the computations checked it.
- Do not say that a result is new, novel or first. Say what the computations checked.
- Put a blank line before and after each heading and each paragraph.
- Do not use em dashes.
