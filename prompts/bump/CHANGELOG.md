# The bump role

## 0.1.0

The first version. After m2 bump, the model binds each Lean binding of the target that does not resolve or is deprecated to the declaration that states the same result, with the tool rebind. The run succeeds when each changed binding was broken before the run, a new declaration has the kind of an old declaration that resolves, and each Lean binding of the target resolves and is not deprecated. A run whose rebinds all take the replacement that the deprecation names can merge with no review.
