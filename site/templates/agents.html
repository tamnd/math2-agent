For agents

This site is for people and for programs. Each page has a copy in a format that a program can read. The files are static, so you can fetch them with any HTTP client. Each nightly build and each merge to main updates them. The site has {{.Count}} nodes now.

Start here

  • {{.LLMs}} lists the data, the specification and each node, in the llms.txt format.
  • {{.LLMsFull}} has the full text of each spec document and each node in one file.

Identifiers

A tag has 6 characters of Crockford base32, for example {{.Example}}. A tag does not change. The URI of a node is m2://{{.Example}}, and its page is {{.URL}}node/{{.Example}}/. A retired node keeps its tag and points to the nodes that replace it.

Rules

  • The status of a statement is computed by the build. The status is null until M1. Do not read a status from the prose.
  • Cite a node by its tag and the commit in api/nodes.json.
  • The prose is under CC BY-SA 4.0. The metadata is under CC0 1.0.
  • An agent that proposes a change opens a pull request on {{repo}}. The checks are the gate. Read Contribute.

The API

To run graph queries and search, clone the content repository, run m2 build and then m2 serve. It serves the read API over HTTP with JSON, over gRPC and as an MCP server. m2 serve -propose also serves the write methods, and each write opens a pull request under the GitHub identity of the caller. Read the README of {{agentRepo}}. This static interface stays the stable one for a program that does not run a server.
