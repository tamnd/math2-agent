Math 2.0

A free knowledge graph of all mathematics. Each node has a permanent tag, its sources, typed links to other nodes and a status that the build computes from the evidence. People read the pages. Agents read the same content as JSON and Markdown.

{{with .Inventory}}

The inventory

The inventory lists {{.Rows}} items of mathematics that external sources present, from {{.Mentions}} mentions. {{.Open}} rows are open: they wait for a node or for a decision. Each row links to the item in its sources. The import workflow adds new rows each week.
